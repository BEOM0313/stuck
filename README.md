# 가치투자 장부

미국 지수 ETF를 핵심으로 두고, 업황 비관 속에서 촉매가 있는 종목을 고르는 개인 가치투자 대시보드예요.

## 구성

- `index.html`: 대시보드 화면 (종목개요, 추천, 내 습관, 매매 기록, 질문하기, 투자 기준)
- `ALGORITHM.md`: 역발상 촉매 가치 점수의 배점, 필터, 매수·매도 규칙과 근거 연구

## 데이터

보유 종목, 매매 기록, 조사 결과, 매매 습관 분석은 `data.enc.json`에 암호화되어 있어요(AES-256-GCM, 비밀번호에서 PBKDF2-SHA256 60만 회로 키 생성). `index.html`을 열고 비밀번호를 넣으면 브라우저 안에서만 복호화돼요.

claude.ai에서 열면 비밀번호 없이 아티팩트 데이터 저장소의 최신 데이터를 바로 불러와요. 이 저장소의 `data.enc.json`은 올린 시점의 사본이에요.

## 주의

이 대시보드의 점수와 판단은 조사를 돕는 도구일 뿐, 투자 권유가 아니에요.
