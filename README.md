# 가치투자 장부

미국 지수 ETF를 핵심으로 두고, 업황 비관 속에서 촉매가 있는 종목을 고르는 개인 가치투자 대시보드예요.

- 화면: https://beom0313.github.io/stuck/
- `index.html`: 대시보드 (종목개요, 추천, 관심, 내 습관, 매매 기록, 투자 기준)
- `ALGORITHM.md`: 역발상 촉매 가치 점수의 배점, 필터, 매수·매도 규칙과 근거 연구
- `data.enc.json`: 보유 종목·매매 기록·조사 결과를 암호화한 파일(AES-256-GCM, PBKDF2-SHA256 60만 회). 페이지에서 비밀번호를 넣으면 브라우저 안에서만 복호화돼요.

질문하기와 투자 기준 저장은 claude.ai 장부에서만 돼요. 이 페이지의 데이터는 마지막으로 올린 시점의 사본이에요.

이 대시보드의 점수와 판단은 조사를 돕는 도구일 뿐, 투자 권유가 아니에요.
